# tatlib

Программный комплекс для автоматического лексического упрощения татарских текстов. Система выполняет морфологический анализ, подбор синонимов с пониженным индексом сложности на базе LLM и обратный морфологический синтез с сохранением грамматической структуры исходного предложения.

## Ключевые возможности

* **Морфологический синтез:** Автоматическое применение правил татарского сингармонизма и ассимиляции согласных при присоединении исходных аффиксов к новым корням.
* **Анализ сложности текста:** Вычисление индекса сложности лексемы и текста в целом на основе частотных словарей, длины токенов и количества морфем.
* **Оптимизация API-запросов:** Система локального кэширования (JSON/SQLite) для минимизации обращений к LLM и предотвращения ошибок ограничения частоты запросов (`429 Too Many Requests`).
* **Параллельная обработка:** Поддержка многопоточного выполнения для анализа объемных корпусов данных (форматы Parquet, TXT).

## Использование пайплайна упрощения

Основной модуль системы. Принимает исходный текст, оценивает сложность корневых морфем, запрашивает упрощенные синонимы и выполняет грамматически корректную сборку.

```python
import json
from tatlib.code.simplifier_core import simplify_text_by_roots

# 1. Загрузка кэшированного частотного словаря корневых морфем
with open("tatlib/data/root_freq_dict.json", "r", encoding="utf-8") as f:
    ROOT_FREQ_DICT = json.load(f)

text = "Ярлы, акчаны алып, өенә кайткан. Бераздан аңа бүтән бер дусты килгән."

# 2. Инициализация процесса упрощения
# target_complexity (0.0 - 1.0) — целевой порог сложности (меньшее значение приводит к более агрессивному упрощению)
new_text = simplify_text_by_roots(
    text=text, 
    target_complexity=0.6, 
    root_freq_dict=ROOT_FREQ_DICT,
    max_workers=5 # Регулирование количества потоков для контроля нагрузки на API
)

print(new_text)
```

## Использование API перевода

Модуль `api_services.py` предоставляет интерфейс для взаимодействия с API TatSoft 2.0, который может использоваться независимо от основного пайплайна.

```python
from tatlib.code.api_services import translate_text

# Перевод с русского на татарский
tat_text = translate_text("Я люблю чак-чак", lang="rus2tat")

# Перевод с татарского на русский
rus_text = translate_text("Мин чак-чак яратам", lang="tat2rus")
```

**Параметры `translate_text`:**
* `text` *(str)*: Исходный текст для перевода.
* `lang` *(str)*: Направление перевода (`"rus2tat"` или `"tat2rus"`).
* `token` *(str, опционально)*: Токен авторизации TatSoft. При отсутствии значения запрос направляется на публичный эндпоинт.
* **Возвращаемое значение:** JSON-объект с ответом сервера.

## Структура проекта

* `simplifier_core.py` — ядро алгоритма: токенизация, оценка корней, синонимизация и морфологический синтез.
* `api_services.py` — модуль интеграции со сторонними сервисами (GigaChat, TuganTel, TatSoft).
* `text_complexity.py` / `word_complexity.py` — вычислители метрик сложности текста и парсеры частотных словарей.
* `corpus_processor.py` / `synonyms_loader.py` — утилиты для агрегации данных и предварительного заполнения кэша синонимов.
