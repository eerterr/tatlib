Дата: 20.09.2026 · модель фазы: Fable 5.1
Канвас (Design-артефакт, приватный, под логином владельца): **https://claude.ai/artifact/5AmucvovT4pXyUNev41YhM**

Шрифты в канвасе загружены как ассеты (TTF с полным набором ә ө ү җ ң һ): Playfair Display 400/400i/600, Golos Text 400/500/600, Literata 400/400i/500. Причина: Google Fonts CSS для Playfair Display отдаёт только subset `cyrillic` без `cyrillic-ext`, и татарские буквы ушли бы в фолбэк. Все стили — в `project/tatlib.css` внутри артефакта, тексты — в разметке артбордов.

## Решения по данным и текстам

- Книги только 4, все из `books`; уровни из `text_complexity` (B1 B1 B1 B2), цифры из `book_stats`, пользователь из `users` / `user_level_state` (имени нет → «Укучы», приветствие без имени).
- Жанры показаны татарскими подписями к значениям базы: «сказка в стихах» → «шигъри әкият», «рассказ» → «хикәя». Год «Нәҗип» пуст → «—».
- Фраза дня — первая строка блока I «Шүрәле» с указанием книги и года; построчного русского перевода в базе нет, поэтому русской строки под ней нет.
- Перевод «һәрьягы» — из глоссария `MockData.shurale` («со всех сторон, вокруг»); в проде перевод даёт `/api/events/word`.
- Приветствие — стандартные формы «Хәерле иртә / Хәерле көн / Хәерле кич» вместо «Иртән хәерле» из мудборда (см. `text-quality-guard`).
- «Һәр укылган бит сине оригиналга якынайта!» (Recap) сохраняет «син» из Figma и кода: обращение приложения к читателю, не к клиенту.
- Фото Казани — заглушки «фото: предоставить» на Welcome и LevelIntro.

## Проверка перед гейтом (`triple-verification`)

1. Программно: в файлах артефакта нет `lorem` / `placeholder` / `ipsum`, нет названий вне четырёх книг («Туган як», «Халык әкиятләре», «Айгуль» — 0 совпадений), баланс `<div>` во всех 23 файлах сходится.
2. Визуально: все 23 артборда сняты headless Chrome (2×) из локального рендера той же разметки и того же CSS с локальными TTF, осмотрены глазами. Найдено и исправлено до гейта: невидимый текст зелёных и ghost-кнопок (специфичность `.tl a{color:inherit}` перебивала `.btn-*`), чипы уровня растянуты на ширину карточки, всплывашка слова уезжала за нижний край, мелкие обложки 56×76 не вмещали заголовок. Буквы ә ө ү җ ң һ на месте во всех трёх шрифтах, включая курсивы.
3. Переходы: ссылки между артбордами проверены по файлам (все `href` указывают на существующие `.dc.html`); клик в самом канвасе — после входа владельца в панель браузера (встроенный браузер не залогинен в claude.ai, вводить учётные данные я не имею права).

## Что не проверил

- Рендер в самом канвасе (support.js, `/_blob`-шрифты) — только локальная копия с теми же файлами; открыть канвас без логина не смог.
- Комментарии владельца на артефакте — читаются через `ArtifactComments` после гейта.
- Реальные переводы слов от бэкенда (Google Translate в `events.py`) — в макете глоссарий мока.
