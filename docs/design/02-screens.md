# TatLib — макеты экранов (фаза 3)

Дата: 20.09.2026 · модель фазы: Fable 5.1
Канвас (Design-артефакт, приватный, под логином владельца): **https://claude.ai/artifact/5AmucvovT4pXyUNev41YhM**
Источники: `design-system/tatlib/MASTER.md` + `pages/reader.md`, `pages/onboarding.md`; расположение — `docs/design/00-ux-map.md`; данные — `backend/tatar_adaptive.db`.

Шрифты в канвасе загружены как ассеты (TTF с полным набором ә ө ү җ ң һ): Playfair Display 400/400i/600, Golos Text 400/500/600, Literata 400/400i/500. Причина: Google Fonts CSS для Playfair Display отдаёт только subset `cyrillic` без `cyrillic-ext`, и татарские буквы ушли бы в фолбэк. Все стили — в `project/tatlib.css` внутри артефакта, тексты — в разметке артбордов.

## Версия 2 (20.09.2026, после правок владельца)

Владелец после первой версии попросил: ближе к мудборду и его примеру (полноэкранное фото Казани, стеклянная форма, тонкие дуги, звёзды-ромбы, фото в арке-куполе, круглые кнопки с узором), больше татарских узоров там, где они стоят в Figma, подача как у Яндекс Музыки / Spotify, без OpenRouter. Сделано своими средствами: канвас Design + база UI/UX Pro Max.

Источники изображений (все из Figma владельца, через `image/batch` файла, скачаны 20.09.2026): триптих обложек 1536×1024 → `cover-su-anasy.jpg`, `cover-shurale.jpg`, `cover-najip.jpg`; портрет Казани с цветущей яблоней 940×1672 → `hero-blossom.jpg`; макет экрана теста → мечеть в арке `arch-mosque.jpg`; макет регистрации → `kremlin-bottom.jpg`; мудборд 1536×1024 → `hero-morning/day/evening.jpg`, `hero-sunset.jpg`. Обложки «Алтын әтәч» в Figma нет: типографика на закатном фото с мотивом 3. Все файлы в `docs/design/mockups/assets/`.

Узоры Figma перерисованы в SVG по макету при 200 % (`gen2.py`, `ORN`): 1 двойной завиток (иконка круглых кнопок и ползунок слоёв, как в Figma), 2 тюльпан-сердце (фланги карточки фразы, карточка «Уку — үсеш» в Recap, как в Figma), 3 тюльпан с ромбом (разделители, водяной знак 4-й обложки), 4 лилия (логотип-росток, кольцо уровня), плюс четырёхконечная звезда в голубом и персиковом (экраны теста, прогресса) и арка-купол с фото (тест, результат). Векторы из Figma по API недоступны без токена, поэтому формы перерисованы вручную и сверены с макетом при 200 %.

Изменения системы (дописаны в MASTER.md § 0): заголовки экранов — Golos Text 600 (как в примере владельца), Playfair Italic остаётся для татарских фраз и обложек; на фото — белая пилюля, на светлом — светло-зелёная `sage2` #C9DDB1 и круглые кнопки `peach2` #F3C7A1 / `sky2` #BFD7EA с узором 1; терракота ушла в акценты. Новые компоненты: стеклянная форма (`.glass`, blur 18), мини-бар «Хәзер укыла» над навигацией, плитки категорий с обложками, страница книги как страница альбома.

## Проверка (`triple-verification`, v2)

1. Программно: 25 файлов, нет `lorem`/`placeholder`, книги только 4, все `href` ведут на существующие артборды; индекс канваса собран поверх версии, сохранённой владельцем в редакторе (ключи `attachments`, `w` у заметок сохранены).
2. Визуально: все 25 артбордов сняты headless Chrome 2× и осмотрены. Найдено и исправлено до публикации: подписи с телефонов мудборда попадали в hero и арку (кропы заменены на чистые источники из Figma), шов размытия на странице книги, плитки поиска перекрывали заголовок, мини-бар на листе компонентов налезал на переключатель, крестик Recap на светлом фоне.
3. Переходы: ссылки по файлам; клик в канвасе — под логином владельца.

## Что не проверил

- Рендер `backdrop-filter` (стекло) внутри самого канваса: в headless Chrome работает, в редакторе канваса не открывал (нет логина в панели).
- Лицензия иллюстраций обложек и фото: они из файла Figma владельца, происхождение владелец знает лучше меня.
