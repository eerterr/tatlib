## 0. Роль и цель

Ты ведёшь полный цикл: ресерч → дизайн-система → макеты всех экранов → перенос в Jetpack Compose → проверка → коммиты в ветку `silvers-rayleigh7` репозитория `tatlib`. Вся работа, все документы, все артефакты живут в этом репозитории и этой ветке. Никаких файлов вне репо, кроме временных в scratchpad.

Продукт: **TatLib** — адаптивное чтение татарской литературы для жителей Республики Татарстан. Читатель проходит тест уровня (A1–C1), получает книгу в трёх слоях текста (оригинал / упрощённый татарский / русский перевод), тапает незнакомые слова, видит прогресс, может отсканировать бумажную книгу. Цель дизайна: приложение должно быть современным, узнаваемым и «своим» для Татарстана, при этом не выглядеть как AI-обои.

Режимы, которые действуют на протяжении всей сессии и вызываются в точке применимости, не «по возможности»:
`/deep`, `Skill(design-stack-mandate)`, `Skill(cool-design)`, `Skill(critical-analysis-first)`, `Skill(no-stale-claims)`, `Skill(stop-slop)`, `Skill(text-quality-guard)`, `Skill(triple-verification)`, `Skill(task-completion-gate)`, `Skill(superpowers:verification-before-completion)`.

## 3. Фаза 1 — Ресерч 10 бенчмарков (параллельные субагенты)

Запуск: `Agent(subagent_type="general-purpose", model="sonnet", run_in_background=true)` — по одному агенту на бенчмарк, все десять одним сообщением. Effort субагентов: medium. Инструменты агентов: WebSearch, WebFetch, Write. `Skill(no-stale-claims)` обязателен внутри каждого промта агента: любой факт о приложении (рейтинг, число установок, фича) — только с URL первоисточника, увиденным сегодня; нет источника — писать «не проверено».

Подбор бенчмарков делать в два круга.

**Круг А — суть продукта (обязательно 6–7 из 10).** Суть TatLib: адаптивное параллельное чтение на изучаемом языке с тапом по словам и уровнями. Искать мировые лидеры в категориях «graded reading / parallel text / language reading / e-reader / learning progress». Кандидаты на проверку (это стартовый список, не итоговый; каждый подтвердить по магазинам приложений и отзывам): Beelinguapp, LingQ, Readlang, Kindle (Word Wise, X-Ray), Яндекс Книги / Bookmate, Duolingo (прогресс и уровни), Drops, Storytel, Литрес, Readwise Reader, Blinkist. Отобрать тех, у кого сильны именно чтение и прогресс, не карточки.

**Круг Б — тюркский и региональный контекст (3–4 из 10).** Проверить, что реально существует и живо в 2026: приложения для татарского («Әйдә! Online», «Татар теле» / проекты Ана теле, продукты Tatsoft и Института языка), казахские (Soyle, Qazaq Grammar и аналоги), турецкие и азербайджанские читалки и приложения о культуре, а также приложения на латинице/кириллице с расширенными наборами букв. Задача круга Б: понять, как локальный контекст решают визуально (орнамент, цвет, шрифт) и где они проигрывают мировым.

Каждый агент пишет `docs/design/benchmarks/<slug>.md` по единому шаблону:

```
# <Название> — <платформы> — <категория>
Источники: [url1], [url2] (дата просмотра 2026-09-20)
1. Что за продукт, для кого, где популярен (страны, оценки в сторах с URL)
2. Главный экран: структура, что первое видит пользователь
3. Экран чтения: типографика, слои/переводы, тап по слову, управление сложностью
4. Прогресс и мотивация: как показаны уровень, серия, статистика
5. Онбординг и тест уровня
6. Визуальная система: палитра (hex, если есть), шрифты, радиусы, иконки, иллюстрации, движение
7. Что берём для TatLib (3 конкретных приёма)
8. Что НЕ берём и почему
9. Скриншоты: ссылки на страницы сторов/пресс-киты (не скачивать бинарники)
```

3. Коммит: `docs: ресерч 10 бенчмарков и синтез`.

Выдачу `search.py` читать критически: BM25 промахивается на узких поджанрах, вывод — вход для рассуждения, не приговор. 21st MCP: вызвать `get_inspiration` и `get_theme` (бесплатные) для категории «reading / education app»; `get_component` не тратить (лимит 2/день), компоненты всё равно пишутся в Compose. Если 21st недоступен — зафиксировать в отчёте, не молчать.

Результат фазы — `design-system/tatlib/MASTER.md` дополненный вручную разделами:

**Цвета.** База из JPEG: крем фона, тёплый тёмно-зелёный для текста и главных кнопок, шалфейный для успеха и прогресса, терракота заката для главного CTA, небесно-голубой и персиковый как вторичные (6 кружков внизу референса). Все hex-значения определить заново по референсу и ресерчу, проверить контраст WCAG AA для текста на креме и на зелёном. Тёмная тема обязательна (читают вечером): не «то же самое, но темнее», а отдельно продуманный набор из тех же семейств. Уровни A1–C1: единая шкала из пяти оттенков, читаемая и в светлой, и в тёмной теме.

**Шрифты.** Два семейства: акцентный с характером для заголовков и татарских фраз (в референсе — серифный с курсивом), рабочий гротеск для интерфейса и длинного чтения. Кандидаты проверять на покрытие **ә ө ү җ ң һ** (и заглавных): скачать TTF из Google Fonts, прогнать

```bash
python3 -c "from fontTools.ttLib import TTFont; f=TTFont('<file>.ttf'); cm=f.getBestCmap(); print([c for c in 'әөүҗңһӘӨҮҖҢҺ' if ord(c) not in cm])"
```

Пустой список = годится. Стартовые кандидаты (проверить, не утверждать): PT Serif / PT Sans (созданы под языки России), Golos Text, Noto Serif + Noto Sans, Literata (Google Play Books), Manrope, Inter. Шрифт для ридера отдельно: длинное чтение, размеры 16–20 sp, интерлиньяж 1.5–1.6, регулировка размера пользователем.

**Якорь (wow-режим `cool-design`).** Один узнаваемый приём, по которому TatLib отличат без логотипа. Кандидаты из ресерча и Figma: татарский орнамент (в Figma есть 4 чёрных мотива) как живая система разделителей, прогресс-колец и пустых состояний; три слоя текста как визуальный жест — «шторка» между оригиналом, упрощённым и русским; рукописная татарская фраза дня как элемент главной. Выбрать один, обосновать в MASTER.md, остальные не тащить. Одно намеренное нарушение сетки — тоже одно. Тест на узнаваемость: закрыть логотип, спросить «чьё это».

**Отсечка AI-дефолта.** Запрещено: градиент фиолетовый→розовый, glassmorphism «потому что модно», карточки с тенью 0/4/16 на всём подряд, стоковые фото случайных людей, иконки от трёх разных наборов. Фотографии Казани из референса допустимы только как настроение онбординга и только если владелец предоставит лицензированные; в макете ставить помеченную заглушку «фото: предоставить», не генерировать «похожее».

**Компоненты.** Кнопки (primary терракота / secondary зелёный / ghost), чипы уровней, карточка книги (обложка, автор, уровень, время чтения — только реальные книги), поле ввода, нижняя навигация 4 пункта, шапка с TAT/RU, слайдер сложности ридера (100 / 50 / 0 %), всплывашка перевода слова, график прогресса, пустые состояния, диалоги. Для каждого — размеры, радиусы, состояния (default / pressed / disabled / focus).

Коммит: `design: дизайн-система TatLib (MASTER.md, страницы reader и onboarding)`.

## 5. Фаза 3 — Макеты в Design-артефакте (главная сессия, Fable 5.1, effort high)

Инструмент: `Artifact` с `action: "quickstart"`, `intent: "design"` → создать артефакт из типа «Design» (`type_url` из ответа quickstart), `title: "TatLib — экраны"`, `auto_open: "after_first_write"`. Следовать инструкциям типа. Дизайн-систем в аккаунте нет, строить из `MASTER.md`. Перед первой строкой вёрстки — `Skill(artifact-design)`.

Артефакт создаётся и открывается **самой сессией** через встроенный инструмент Artifact под логином claude.ai владельца. Сайт claude.ai/design открывать не нужно, репозиторий к нему не подключать, hand-off не делать: сессия уже в репо. Итог фазы — ссылка вида `https://claude.ai/artifact/...` в сообщении владельцу; артефакт также виден в галерее claude.ai/code/artifacts. Правки после гейта делать в тот же артефакт по тому же адресу (publish с `url`), новый не создавать. Комментарии владельца на странице артефакта читать через `ArtifactComments`.

Канвас: артборды 390 × 844 (Android-пропорции), группами по флоу из `00-ux-map.md`:

1. Splash, Welcome («Изучай татарский легко» / татарская версия), выбор входа
2. Регистрация (имя, телефон/почта, пароль, повтор, возраст 10–14 / 14–18 / 18–25 / 25+), вход
3. Тест уровня: интро, вопрос 1/5 с вариантами, результат с выбором A1–C1 вручную
4. Главная: приветствие по времени суток (Иртән / Көндез / Кич хәерле, имя пользователя из базы — тестовый пользователь без имени, значит «Исәнме!»), текущая книга с прогрессом, «Минем китапларым», «Тәкъдим итәбез» — все карточки из 4 реальных книг
5. Поиск «Эзләү» с фильтрами (все / книги / авторы / темы), результаты — те же 4 книги
6. Детали книги: обложка, автор, жанр, уровень, статистика из `book_stats`, кнопка «Укырга»
7. Ридер: три слоя текста реального фрагмента «Шүрәле» из `text_blocks`, тап по слову с переводом, слайдер сложности, настройки шрифта; светлая и тёмная версии
8. Recap после сессии: реальные поля (страниц, новых слов, процент оригинала) — если сессий в базе нет, показать пустое состояние
9. Прогресс «Алгарышың»: вкладки неделя / месяц / год, уровень, график, фраза дня
10. Сканер: камера, распознавание, результат
11. Профиль и настройки (TAT/RU, тема, размер шрифта)
