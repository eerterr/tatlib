## 1. Что за продукт, для кого, где популярен
- **Soyle** (soyle.kz) — государственный проект Фонда развития государственного языка Казахстана, автор идеи Азат Шаукенов/Шауеев, директор фонда (soyle.kz/article/view/165). Портал + мобильные приложения для изучения казахского с нуля до продвинутого уровня, есть детский раздел. На самом портале указано число обучающихся — «498695 человек» (soyle.kz). App Store: рейтинг **2.8 из 5 (6 оценок)** — исправлено по факту WebFetch 2026-09-20 (в исходном черновике ошибочно стояло «3.3 из 5, 63 оценки», на странице сегодня показано «2,8 из 5 Оценок: 6»), версия 3.1.4, обновлено 10 сентября (apps.apple.com/Soyle).
- **Soyle Pro** — отдельное приложение того же разработчика (Azat Shauyeyev). «Duolingo-формат» — **не проверено**: ни soyle.kz/article/view/165, ни qazaq-found.kz/rus/?p=4898 (WebFetch 2026-09-20) слова «Duolingo» не содержат; qazaq-found.kz описывает Soyle Pro как «созданное по аналогии с лучшими иностранными приложениями», без названия Duolingo. App Store: рейтинг 3.6 из 5 (25 оценок), доступ полностью 1000 ₸ (пункт «Полный доступ!» подтверждён на странице покупок), iOS 12.0+ (apps.apple.com/Soyle Pro).
- **Qonzhyq App** — казахстанский стартап, объединяющий фольклор (песни, кюи, сказки) и обучение языку для детей и взрослых, разработчик по App Store — IS HOLDING, TOO. App Store: рейтинг 4.6 из 5 (163 оценки), версия 2.7.0, обновлено 3 мая (apps.apple.com/Qonzhyq).
- **Aıtý** — приложение одного разработчика (Сансызбаи Оспанов), фокус на 300 самых частотных словах казахского языка. App Store: рейтинг 4.6 из 5 (1.1k оценок) (apps.apple.com/Aıtý).

## 2. Главный экран: структура
- Soyle (веб-портал, структура повторяется в приложении): разделы «Уроки» (A1–C2, по 10 уроков на уровень), «Детям», «Тематический словарь», «Говорим» (аудио-разговорник), «Слово дня» — источник soyle.kz/article/view/691 сегодня отдаёт HTTP 404 (WebFetch 2026-09-20); структура переподтверждена на рабочей странице [soyle.kz/article/view?id=216](https://soyle.kz/article/view?id=216).
- Qonzhyq App: два крупных блока на входе — образовательный раздел (алфавит, цифры, цвета, животные для детей; для взрослых — новый модуль Sabaq) и фольклорный каталог (500+ народных песен, 450+ кюев, 160+ детских песен, 250+ сказок) (qonzhyq.app/aboutapp-ru).
- Aıtý: первый экран — список из 300 слов повседневной речи, без выраженной модульной структуры «Уроки/Словарь» (apps.apple.com/Aıtý).

## 3. Экран чтения: типографика, слои, тап по слову, сложность
Функции TatLib (три слоя текста, тап по слову с переводом в тексте) ни на одном из первоисточников явно не подтверждены — не проверено. Ближайшие аналоги:
- Soyle: «озвучка и перевод новых слов, карточки слов, словари уроков» — перевод привязан к словам урока, а не к тексту книги (soyle.kz/article/view/165).
- Qonzhyq: «синхронизация текста со звуком» (караоке-подсветка) — **не проверено**: при повторном WebFetch qonzhyq.app/aboutapp-ru, qonzhyq.app/ru и apps.apple.com/Qonzhyq 2026-09-20 такая формулировка не найдена ни на одной из трёх страниц; подтверждён только состав каталога (500+ песен, 450+ кюев, 160+ детских песен, 250+ сказок).
- Aıtý: список слов со статистикой по каждому, без экрана «текст + перевод» (apps.apple.com/Aıtý).

## 4. Прогресс и мотивация

## 6. Визуальная система
Hex-коды палитры, названия шрифтов и радиусы компонентов ни на одном официальном источнике не опубликованы — не проверено (WebFetch отдаёт HTML→markdown без CSS, живых скриншотов в Google Play открыть не удалось). Что подтверждено текстом:
- Soyle: «чистый, современный интерфейс», есть режим для слабовидящих; заметных орнаментов в основном интерфейсе нет, казахские культурные мотивы (пословицы, высказывания Абая, традиции) вынесены в контент продвинутого уровня C2, а не в UI-стиль (soyle.kz).
- Soyle (App Store): версия 3.0+ отмечена как «обновлён дизайн интерфейса» — направление редизайна не раскрыто (apps.apple.com/Soyle).
- Qonzhyq: сайт декларирует культурно-фольклорную тему через иллюстративный контент разделов, но конкретная палитра/шрифт/иконография в тексте не названы (qonzhyq.app/ru).
- Aıtý: в отзывах пользователей встречаются формулировки «super clear and fun», «beautiful app» — не является спецификацией дизайна, а мнением, поэтому не берём как факт стиля (apps.apple.com/Aıtý).

## 7. Что берём для TatLib
1. Явная кнопка теста уровня на входе («Узнать свой уровень?», Soyle) — TatLib уже планирует тест A1–C1, стоит вывести его на первый экран как основное CTA, а не спрятать в настройках.
2. Сертификат/порог прохождения (60%+ у Soyle) как видимая цель уровня — даёт пользователю понятный критерий «уровень закрыт», это применимо к слоям упрощённого текста TatLib.
3. Синхронизация текста со звуком у Qonzhyq (караоke-подсветка строки при чтении сказок) — механику подсветки текущего фрагмента стоит перенести на экран чтения TatLib при переключении между оригиналом/упрощённым слоем/переводом.

## 8. Что НЕ берём и почему
- Дробление на отдельные приложения под каждую задачу (Soyle + Soyle Pro как два разных продукта одного разработчика) — путает пользователя, TatLib должен остаться одним приложением.
- Перевод, привязанный только к отдельным словам урока (Soyle), а не к произвольному слову в тексте книги — для TatLib с чтением книг это узкое место, надо делать тап по любому слову, а не по заранее размеченному списку.
- Смешение фольклорного медиакаталога и языкового курса в одной навигации (Qonzhyq) — для TatLib это распыление фокуса, книга и словарь важнее каталога песен.
