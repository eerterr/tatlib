# Amazon Kindle — iOS/Android/Web — приложение для чтения книг (эталон ридера, круг А)
Источники: https://apps.apple.com/us/app/amazon-kindle-reading-app/id302584613, https://kdp.amazon.com/en_US/help/topic/G202187230, https://www.aboutamazon.com/news/devices/kindle-app-guide, https://www.aboutamazon.com/news/devices/what-you-can-do-with-a-kindle, https://www.aboutamazon.com/news/books-and-authors/kindle-accessibility-features-for-all-readers, https://www.aboutamazon.com/news/devices/fun-kindle-features, https://www.aboutamazon.com/news/devices/kindle-scribe-new-features, https://press.aboutamazon.com/2015/6/amazon-introduces-new-kindle-paperwhite-the-most-popular-kindle-now-even-better-still-only-119, https://press.aboutamazon.com/2013/9/introducing-the-all-new-kindle-paperwhite-the-6th-generation-of-kindle, https://play.google.com/store/apps/details?id=com.amazon.kindle (дата просмотра 2026-09-20)

## 1. Что за продукт, для кого, где популярен
Amazon Kindle: Reading App — бесплатное приложение для чтения купленных Kindle-книг, подписки Kindle Unlimited (1+ млн книг) и 1000+ книг в составе Amazon Prime; работает без отдельного устройства Kindle (https://apps.apple.com/us/app/amazon-kindle-reading-app/id302584613). Разработчик — AMZN Mobile LLC. Не позиционируется как приложение для изучения языка — это универсальный ридер для читателей на английском и других языках, которыми пользуется книжный каталог Amazon.
App Store (открыто через WebFetch 2026-09-20): рейтинг 4.9 из 5, 5.8 млн оценок, #4 в категории Books (США), возрастной рейтинг 13+, требует iOS/iPadOS 17.0+, вес 205.4 МБ, локализация — английский + 9 языков, включая испанский, французский, немецкий, японский, португальский, китайский (https://apps.apple.com/us/app/amazon-kindle-reading-app/id302584613).
Google Play: карточка приложения (id=com.amazon.kindle) открывалась через WebFetch четыре раза подряд — контент страницы каждый раз обрезался инструментом до пустого результата, рейтинг и число установок на Google Play: не проверено. Страны/регионы особой популярности: не проверено.

## 2. Главный экран: структура, что первое видит пользователь
Навигация — нижние вкладки Home, Library, More (https://www.aboutamazon.com/news/devices/kindle-app-guide). «Вкладка Home внизу экрана ведёт на главный экран Kindle, где находится секция From Your Library — книги, которыми пользователь уже владеет» (там же). После входа в аккаунт вся библиотека Kindle автоматически появляется на вкладке Library (там же). Остальная часть главного экрана заполнена рекомендациями книг, которые можно листать, скачивать сэмплы и добавлять в список покупок на сайте Amazon; наверху — баннер с категориями/жанрами для быстрого доступа (там же). Вкладка More открывает Reading Insights (статистика чтения), вишлист, настройки семейного доступа к книгам и Settings (там же).

## 3. Экран чтения: типографика, слои/переводы, тап по слову, управление сложностью
Слоёв текста (оригинал/упрощённый/перевод) в Kindle нет — это ридер для одноязычных книг, тап по слову открывает единый built-in словарь, X-Ray и переводы, а не параллельный текст (https://apps.apple.com/us/app/amazon-kindle-reading-app/id302584613).
**Word Wise** — «функция, которая позволяет смотреть определения слов либо показывает синонимы, отображённые в строке над более сложными словами во время чтения, чтобы расширять словарный запас» (https://www.aboutamazon.com/news/devices/what-you-can-do-with-a-kindle). Доступна только для книг на английском языке и включена не во всех книгах; наличие проверяется по надписи «Word Wise: Enabled» / «Word Wise: Not Enabled» на странице товара (там же).
**X-Ray** — «фича Kindle, похожая на энциклопедическую статью о книге, которую читаешь», может включать сведения о сюжете, местах, персонажах; открывается тапом по верхней части страницы → меню из трёх точек → X-Ray; есть не в каждой книге (https://www.aboutamazon.com/news/devices/fun-kindle-features). X-Ray показывает информацию о персонаже, теме, событии, месте или другом термине по долгому нажатию на слово/фразу; источник — авторский текст (до 1200 символов) или автосгенерированные описания и ссылки на Wikipedia; доступен только для англоязычных книг; текстовые ссылки, не изображения (https://kdp.amazon.com/en_US/help/topic/G202187230).
Тап по слову даёт словарь, Wikipedia lookup, мгновенные переводы («Look up words, people, and places while you read» — built-in dictionary, X-Ray, Wikipedia lookup, instant translations) (https://apps.apple.com/us/app/amazon-kindle-reading-app/id302584613). Управление сложностью текста как отдельной фичи (упрощение уровня) в открытых источниках не встретилось — не проверено.

## 4. Прогресс и мотивация: как показаны уровень, серия, статистика
Приложение отслеживает прогресс чтения, включая «real page numbers» для большинства топовых тайтлов, синхронизацию между устройствами (https://apps.apple.com/us/app/amazon-kindle-reading-app/id302584613). **Reading Insights** — раздел вкладки More, даёт «статистику о твоей истории чтения» (https://www.aboutamazon.com/news/devices/kindle-app-guide). Конкретные метрики (streak, дни чтения, минуты, календарь активности) внутри Reading Insights официальным источником сегодня не подтверждены — не проверено (страница https://www.amazon.com/kindle/reading/insights несколько раз возвращала HTTP 503 при попытке открыть через WebFetch).

## 5. Онбординг и тест уровня
Kindle не позиционируется как языковое приложение, входного теста уровня (A1–C1 и т.п.) в проверенных источниках нет — не проверено / не применимо к продукту такого типа. Онбординг, судя по официальному гайду, сводится к входу в аккаунт Amazon, после чего библиотека автоматически подгружается на вкладку Library (https://www.aboutamazon.com/news/devices/kindle-app-guide). Экраны первого запуска, выбора цели чтения и т.п.: не проверено.

## 6. Визуальная система: палитра (hex), шрифты, радиусы, иконки, иллюстрации, движение
**Шрифт Bookerly** — эксклюзивный шрифт, «разработанный с нуля для чтения на цифровых экранах», тёплый и современный, вдохновлён лучшими шрифтами печатных книг, «созданный вручную для отличной читаемости при любом размере»; заявлена цель — «читать быстрее с меньшим напряжением глаз» за счёт более лёгкого начертания (https://press.aboutamazon.com/2015/6/amazon-introduces-new-kindle-paperwhite-the-most-popular-kindle-now-even-better-still-only-119). Тот же релиз описывает движок типографики: переносы и улучшенные словесные интервалы, кернинг и лигатуры, drop caps и адаптация изображений «как задумал автор», автоподбор полей/колонок при увеличении шрифта (там же). Дополнительно доступен шрифт **OpenDyslexic** — «некоторые читатели считают, что он улучшает читаемость» (https://www.aboutamazon.com/news/books-and-authors/kindle-accessibility-features-for-all-readers). Название и наличие шрифта Amazon Ember в приложении сегодня официальным источником не подтверждено — не проверено.
Настройка текста: размер, поля и интервалы (между строками, абзацами, словами, символами), выравнивание — по левому краю или по ширине; по левому краю плюс увеличенные интервалы и поля «снижают напряжение глаз и улучшают фокус» для части читателей (https://www.aboutamazon.com/news/books-and-authors/kindle-accessibility-features-for-all-readers). Приложение позволяет «сохранить и переиспользовать предпочитаемые настройки» — то есть именованные пользовательские темы чтения (там же).
**Тёмная тема**: «чтобы включить дневной/тёмный режим — смахнуть вниз с верха экрана, открыть Quick Actions, нажать Dark Mode» — белый текст на чёрном фоне, особенно для вечернего чтения (https://www.aboutamazon.com/news/devices/what-you-can-do-with-a-kindle; формулировка про Quick Actions относится к устройствам Kindle, для приложения — переключатель цвета страницы в «Aa»-меню, отдельно не проверено дословно). На новых устройствах Kindle Scribe/Colorsoft система дала выборочный тёмный режим — можно включить тёмную тему для Home/Library/Settings, оставив страницы книг светлыми (https://www.aboutamazon.com/news/devices/kindle-scribe-new-features) — это про Kindle-устройство, не про мобильное приложение, для приложения такая выборочность не проверено.
Hex-коды палитры интерфейса, радиусы элементов, иконография, иллюстрации, анимации переходов страниц: не проверено — в открытых официальных материалах не публикуются.

## 7. Что берём для TatLib (3 конкретных приёма)
- Word Wise как приём: не открывать словарь модалкой на каждый тап, а печатать короткую подсказку (перевод/синоним) прямо над сложным словом в строке — для TatLib логично встроить такую подсказку для слов упрощённого/оригинального слоя, доступную переключателем, а не поверх каждого слова принудительно.
- Reading Insights как отдельный раздел статистики за пределами экрана чтения (в More/профиле, не перегружая сам ридер) — для TatLib завести аналогичный раздел с историей чтения отдельно от процесса тестирования уровня.
- Именованные, сохраняемые пользовательские темы чтения (шрифт + интервалы + поля + выравнивание одним пресетом «сохранить и переиспользовать») — для TatLib вместо разрозненных тумблеров дать 1–2 сохранённых профиля чтения (например, «на экзамен» / «расслабленно»).

## 8. Что НЕ берём и почему
- X-Ray с персонажами/событиями/энциклопедией книги — функция заточена под длинную прозу с богатым миром (романы), у TatLib короткие учебные тексты для отработки языка, овербилд для MVP.
- Ставка на built-in Wikipedia-lookup и «real page numbers» синхронизации между множеством форматов устройств — инфраструктура большого книжного магазина Amazon, несоразмерна масштабу TatLib.
- Тёмная тема как системная привязка к нескольким поверхностям устройства (выборочно Home/Library светлые, страницы книги тёмные, как на Kindle Scribe) — слишком гранулярная настройка для одного read-экрана TatLib, достаточно единого переключателя light/dark на всё приложение.
