## 1. Что за продукт, для кого, где популярен

- Duolingo — бесплатное приложение для изучения 40+ языков короткими уроками: говорение, чтение, аудирование, письмо (App Store).
- Отдельно в экосистеме — Chess, Math, Music (App Store).
- Разработчик — Duolingo, Inc. Категория — Education (App Store).
- «Apple named it iPhone App of the Year» — не проверено: на странице App Store сегодня (WebFetch 2026-09-20) эта фраза не найдена, вместо неё страница показывает статус «Editors' Choice»; исторический факт награды 2013 года подтверждён только сторонними источниками (CMU, The Epoch Times), не первоисточником Apple на дату просмотра.
- Рейтинг в App Store: 4.7 из 5, 5.5 млн оценок (App Store, просмотрено 2026-09-20).
- Google Play (id=com.duolingo) — рейтинг и число установок — **не проверено**: страница рендерится через JS, WebFetch сегодня трижды вернул только пустой каркас без текста листинга.
- Страны/регионы наибольшей популярности — **не проверено**: официального рейтинга по странам на первоисточниках сегодня не найдено.

## 2. Главный экран: структура, что первое видит пользователь

- Домашний экран после редизайна — не дерево навыков, а линейный «путь» (path) из кружков-уровней; каждый кружок = один уровень (раньше — «crown level») (Home screen redesign).
- Stories и практика встроены прямо в путь, а не вынесены в отдельные вкладки (Home screen redesign).
- Уроки сгруппированы в юниты (units) с гайдбуками — подсказками по теме юнита (Home screen redesign).
- В правом нижнем углу — плавающая стрелка для перехода между секциями пути (Home screen redesign).
- Нижнее меню включает Quests (иконка сундука) и Practice Hub (иконка гантели, для подписчиков Super) (Home screen redesign).
- Дизайн-обоснование — «hover method»: уровни разных навыков чередуются вдоль пути вместо полного прохождения одного скилла подряд, чтобы работал интервальный повтор (Home screen redesign).

## 3. Экран чтения: типографика, слои/переводы, тап по слову, управление сложностью

- Тап-по-слову перевод — **не проверено**: прямого описания в открытых материалах блога не найдено.
- Стандартные уроки построены на переводе, аудировании, письме (App Store).
- Отдельная фича для протяжённого чтения — Stories, разбор в разделе 5.
- Визуальный стиль текста и иллюстраций — «bold, bouncy, and bright», минималистичная «playful» эстетика (Shape language).
- В 2018 стиль сменился со «статичных жёстких форм на светло-сером фоне» на «яркие цвета и закруглённые кнопки на белом фоне» (Shape language).
- Принцип иллюстрации — минимум векторных форм для узнаваемости объекта на маленьком экране, белое негативное пространство для чистоты кадра (Shape language).
- Конкретные значения типографики экрана чтения (кегль, интерлиньяж) — **не проверено**.

## 4. Прогресс и мотивация: как показаны уровень, серия, статистика

**Уровень/скор**
- Курсы делятся на секции (sections) → юниты (units) → уроки.
- Duolingo Score 59 ≈ A2, Duolingo Score 100–129 ≈ B2, «B2 — четвёртый из шести уровней CEFR» (Courses teach advanced content).
- Секции 5–6 курса покрывают B1, секции 7–8 — B2, с формулировкой цели для каждой секции, например «I can participate in daily life in English» (How Duolingo teaches English).
- Полная официальная таблица «секция → CEFR» для всех языков — **не проверено**, в открытых блог-статьях не найдена.

**Серия (streak)**
- Стрик считается по выполнению дневной цели каждый день; пропуск одного дня обнуляет серию (Streaks blog).
- Отображается «flame icon на верхней панели» домашнего экрана рядом со счётчиком дней (Streaks blog).
- Заморозка серии — «Weekend Amulet», покупной предмет, сохраняющий серию на выходные без захода в приложение; даёт +4% возврата через неделю и на 5% меньше потерь серии (Streaks blog).
- Падение активности по выходным без амулета — 5–10% от буднего пика (Streaks blog).
- Friend Streak — общая серия с друзьями (до пяти), со своими анимациями по вехам (Streaks blog, Product highlights 2025).
- Психология — loss aversion: пользователи «крайне не хотят терять» серию; опция «взять паузу» повышает долгосрочное удержание сильнее, чем «забег» без перерывов (Streaks blog).
- В 2025 добавлены новые анимации для вех серии (Product highlights 2025).

**Статистика и лиги**
- Еженедельная статистика (XP, число уроков, активные дни, время за неделю) упоминается в контексте email-рассылки — источник не первоисточник, **частично не проверено**.
- Лиги: еженедельный сброс каждое воскресенье по часовому поясу пользователя; сопоставление по «похожим учебным привычкам» и часовому поясу (Leagues/Leaderboards blog).
- Система расширена с 5 до 10 лиг (Leagues/Leaderboards blog).
- Топ-10 учеников Diamond League попадают в турнир (четвертьфинал/полуфинал/финал); турнир пока на iOS и Web, Android — «coming soon» (Leagues/Leaderboards blog).
- Названия всех 10 лиг по порядку — **не проверено**: в открытой статье поимённо упомянуты только Amethyst и Diamond.
- Achievement Badges — «Personal Records»: максимум XP за день, самая длинная серия, Perfect Lessons, Highest League finish; значки собраны в одном месте профиля «как трофеи на полке», есть редкие бейджи для «преданных учеников» (Achievement badges blog).

## 5. Онбординг и тест уровня

- Путь нового пользователя: скачать приложение → выбрать язык → ответить на вопросы о мотивации и целях → включить уведомления → выбрать старт «с нуля» или «пройти placement-тест» → создать профиль для сохранения прогресса (Duolingo 101 blog).
- После размещения через тест «нельзя отменить» результат и начать заново (Duolingo 101 blog).
- Placement test адаптивный: после каждого вопроса оценка уровня пересчитывается, следующий вопрос подбирается под новую оценку (Placement test blog).
- Тест начинается с простых вопросов; при верных ответах сложность растёт (Placement test blog).
- Итоговое размещение зависит от сложности заданных вопросов и правильности ответов; по итогу «открываются» скиллы, которые пользователь предположительно уже знает (Placement test blog, статья 2018 года — актуальность для текущей версии теста дополнительно не проверялась).
- Прямая привязка результата теста к конкретным CEFR-меткам — **не проверено**, в статье не описана.
- Точная длительность теста в минутах — **не проверено**, в открытой статье не указана явно.

## 6. Визуальная система: палитра (hex), шрифты, радиусы, иконки, иллюстрации, движение

- Официальный брендбук `design.duolingo.com`, включая страницу `/identity/color`, на 2026-09-20 отдаёт 301-редирект на `blog.duolingo.com/hub/design/`; отдельной публичной страницы с hex-кодами палитры и типографикой на первоисточнике не обнаружено (Duolingo design hub).
- **Hex-коды палитры — не проверено.** Сторонние подборки бренд-цветов существуют, но как единственный источник не используются по правилу skill'а.
- По статье о художественном стиле — цвета «vibrant», формы «rounded», без конкретных hex или значений радиуса (Shape language).
- **Названия шрифтов (Feather Bold, DIN Next Rounded) — не проверено на первоисточнике.** Они фигурируют только в сторонних дизайн-обзорах (Fonts In Use, Monotype, note.com), прямого подтверждения на blog.duolingo.com/design.duolingo.com сегодня не найдено.
- Движение/анимация подтверждено первоисточником: «свежие анимации для вех Streak» (Product highlights 2025); в редизайне пути — анимированные персонажи, «подбадривающие на пути» (Home screen redesign).
- Тёмная тема — **не проверено**: справочная статья о Dark Mode существует по URL на `support.duolingo.com` (немецкая версия проиндексирована), но полный текст WebFetch сегодня не отдал, поэтому механика тёмного режима (палитра, автопереключение по системе) не подтверждена.

## 7. Что берём для TatLib

1. **Линейный «путь» вместо дерева, с юнитами и секциями, каждая секция = осмысленный CEFR-диапазон** (Home screen redesign, How Duolingo teaches English) — для TatLib это прямой аналог: секции A1→C1 как путь, юнит = одна книга/подборка текстов, а не абстрактное «дерево уровней».
2. **Streak с заморозкой и мягким прощением пропуска, а не только штрафом** (Streaks blog: пауза повышает удержание сильнее, чем «забег» без перерывов) — для чтения татарской литературы это снижает тревожность вокруг ежедневного объёма и подходит долгому чтению книги, а не спринтам уроков.
3. **Placement test — адаптивный, начинается с лёгкого и подстраивается по каждому ответу, результат — открытие уровня, а не «сдал/не сдал»** (Placement test blog) — для TatLib это модель первого теста A1–C1: не жёсткий экзамен, а быстрая калибровка перед выбором книги нужной сложности.

## 8. Что НЕ берём и почему

- **Лиги/еженедельное соревнование с 10 дивизионами** (Leagues/Leaderboards) — механика заточена под ежедневные короткие уроки и массовую социальную конкуренцию; для чтения книги в трёх слоях текста соревновательное давление скорее мешает вдумчивому чтению, чем помогает.
- **Жёсткая привязка прогресса к XP/лигам как основной метрике успеха** — у TatLib успех — это дочитанная книга и понимание оригинала, а не скорость набора очков; копирование XP-гонки Duolingo сместило бы фокус с качества чтения на объём кликов.
